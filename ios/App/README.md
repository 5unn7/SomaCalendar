# Soma for iOS

Capacitor 8 app around the shared web app in `src/redesign` (built to `www/` by `npm run bundle`), plus a native
WidgetKit widget. Android uses the same `www/` through the Capacitor project in `android/`.

| Piece | File |
| --- | --- |
| Capacitor host, background colour, plugin registration | `App/SomaBridgeViewController.swift` |
| Soma plugin: widget feed to the App Group, add to calendar | `App/SomaPlugin.swift` |
| `window.SomaNative` on top of Capacitor plugins (reminders, location, haptics) | `src/redesign/native.js` |
| Home Screen and Lock Screen widget | `SomaWidget/SomaWidget.swift`, `Shared/WidgetFeed.swift` |
| Simulator tests against the launched app | `AppTests/SomaTests.swift` |

Minimum iOS 17. Bundle ID `app.soma.calendar` (change `SOMA_BUNDLE_ID` in `project.yml` before the first upload; it is permanent after).
The widget and app share data through the App Group `group.<bundle id>`.

## Build on a Mac

```sh
npm ci && npm run bundle && npx cap sync ios
brew install xcodegen
cd ios/App && xcodegen && open App.xcodeproj
```

The Xcode project is generated by XcodeGen from `project.yml`; Capacitor writes `CapApp-SPM/Package.swift`, `App/public`
and `App/capacitor.config.json` on every `npx cap sync ios`.

## CI

- `.github/workflows/ios.yml` builds every PR that touches the app, runs the simulator tests and saves a screenshot.
- `.github/workflows/ios-release.yml` runs on a `v*` tag and uploads a signed build to TestFlight. It needs repository
  secrets `APPLE_TEAM_ID`, `ASC_KEY_ID`, `ASC_ISSUER_ID` and `ASC_KEY_P8` (an App Store Connect API key with the App Manager role).
  It never submits for App Review.
