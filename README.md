# Soma Calendar

Offline-first Android lunar calendar and Panchang using [Grahan](https://github.com/svarbhanu/grahan) (MIT).

This repository contains an early prototype, not a published app. The app is designed without accounts, ad tracking, or location permissions. Panchang calculations and cultural interpretations must be validated before public release.

See the GitHub Actions `Build Android APK` workflow for an installable debug APK when the build succeeds.
